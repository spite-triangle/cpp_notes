本文档系统介绍了 Vue 3 渐进式前端框架的核心知识体系。从项目初始化入手，讲解基于 Vite 的 Vue 工程搭建与文件结构；随后深入模板语法、数据绑定（v-bind / v-model）及事件处理等基本概念。脚本开发部分对比选项式 API 与组合式 API，介绍 setup 语法糖与 Hooks 代码组织模式。响应式数据系统涵盖 ref / reactive / computed 等核心 API，并配套 watch 与 watchEffect 侦听器实现数据变化监听。组件章节详解生命周期、props 通信、插槽内容分发及 Teleport / Suspense 功能。进阶部分涵盖 Vue Router 单页路由配置（含嵌套路由、参数传递与导航守卫）、Pinia 状态管理（Store / Getters / Actions），以及 Vite 构建工具的路径别名、跨域代理与环境变量管理等工程化配置。
